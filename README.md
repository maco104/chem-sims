# chem-sims

Public copies of the browser simulations used in CHEM 1050, served by GitHub Pages so students can open them
with no sign-in:

- Site: https://maco104.github.io/chem-sims/
- Equilibrium Snowball Fight (Ch. 9): https://maco104.github.io/chem-sims/ch09-equilibrium-sim.html

Each simulation is one self-contained HTML file.

## Where the source lives

The working copy of every simulation is in the private `maco104/courses` repo, next to its worksheet
(for example `chem1050/worksheets/ch09-equilibrium-sim.html`). This repo only holds published copies:
change the file in `courses` first, then copy it here unchanged, keeping the same file name so the link
students already have keeps working.

Nothing else from `courses` belongs here: everything in this repo is public.
